# Hadron AI Project

An AI-powered hadron analysis and visualization system based on the quark model of particles.

## Features

- Hadron classifier
- Particle database
- Quark composition analysis
- NLP chatbot
- Particle visualization
- Semantic search engine

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

## How to Run

```bash
streamlit run app.py
```

## Project Goal

To build an interactive AI-based physics platform for studying hadrons and particle interactions.
